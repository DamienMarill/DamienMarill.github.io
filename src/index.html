Comment une idée finit dans le carnet.

  1. 1

    Je code un truc

    Un outil pour mes étudiants, un jeu pour tester une techno, une idée qui me trotte dans la tête. En dehors des projets clients.

  2. 2

    Je le publie

    Le dépôt part sur GitHub avec une page GitHub Pages. Pas de polish obligatoire : c'est un labo.

    Il atterrit ici

    Toutes les 6 heures, le carnet relève les dépôts publiés, photographie chaque page et met sa fiche à jour.
